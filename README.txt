DC OVERWATCHER LEGAL PAGES — GITHUB PAGES GUIDE

1. Create a NEW PUBLIC GitHub repository named: dc-overwatcher-legal
2. Open it > Add file > Upload files.
3. Upload index.html, terms.html, privacy.html and commit changes.
4. Repository Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment. Settings > Pages shows the published URL.
8. Verify the actual pages load:
   https://YOUR-GITHUB-USERNAME.github.io/dc-overwatcher-legal/terms.html
   https://YOUR-GITHUB-USERNAME.github.io/dc-overwatcher-legal/privacy.html
   Replace YOUR-GITHUB-USERNAME and do not use these URLs until they load.
9. Developer Portal > DC Overwatcher > General Information:
   Terms of Service URL = actual URL ending /terms.html
   Privacy Policy URL = actual URL ending /privacy.html
10. Save, then revisit App Verification.

Official guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

IMPORTANT: These are templates, not legal advice. Review against the deployed bot before publishing. GitHub Pages is public. Never upload .env, tokens, databases, logs, or private bot data.
